# Masked Visual Actions 与 MAE 的联系和区别

## 对比对象

- **Masked Visual Actions（MVA）**：*Masked Visual Actions for Unified World Modeling*，面向机器人世界建模，将实体的时空像素轨迹作为动作条件。
- **MAE**：He et al., *Masked Autoencoders Are Scalable Vision Learners*，arXiv:2111.06377，面向视觉自监督表征学习，通过重建被随机遮蔽的图像 patch 预训练 ViT。

## 结论先行

二者确实共享一个高层抽象：

```text
给出部分可见信息 → 建模条件分布 → 补全其余内容
```

但不能把 MVA 直接理解为“视频版 MAE”。更准确的概括是：

> **MAE 使用 mask 构造自监督表征学习任务；MVA 将 mask 本身设计成具有动作语义的时空控制接口。**

一句话区分：

> **MAE 是 mask to learn representations；MVA 是 mask as action to query a world model。**

## 共同点：都属于掩码条件补全

### MAE

MAE 随机遮蔽输入图像中约 75% 的 patch，只把未遮蔽 patch 交给编码器；轻量解码器接收可见 patch 表征和 mask token，重建原始图像中缺失的像素：

```text
随机可见图像 patch
→ 编码可见内容
→ 重建被遮蔽 patch
```

它通过人为制造高比例信息缺失，让模型学习图像的结构和语义规律。

### MVA

MVA 给模型提供初始参考帧以及某些实体被揭示的时空轨迹，再生成完整交互视频：

```text
初始帧 + 被揭示实体的时空轨迹
→ 条件视频补全
→ 完整的机器人—物体—环境演化
```

MVA 将视频视为实体轨迹的联合分布：

$$
p(V)=p(e_1,e_2,\ldots,e_n).
$$

对条件实体集合 $S$，构造二值时空掩码：

$$
M(S)=\bigcup_{i\in S}e_i,
\qquad
p_\theta\bigl(V\mid M(S)\odot V,I_0\bigr),
$$

其中 $I_0$ 是初始参考帧。模型看到的是被揭示实体在视频画布中的运动，其余区域则由视频生成模型补全。

因此，两者的共同形式都是：

$$
p(\text{missing content}\mid\text{visible content}).
$$

## 核心区别：mask 在两个方法中扮演不同角色

| 维度 | MAE | Masked Visual Actions |
|---|---|---|
| 掩码对象 | 随机图像 patch | 具有语义的实体时空区域 |
| 可见内容 | 约 25% 的静态图像 patch | 机器人或物体在多帧中的像素轨迹 |
| 被预测内容 | 被遮蔽的静态图像像素 | 机器人、物体和环境的完整视频演化 |
| mask 的作用 | 制造自监督学习难题 | 表达动作、目标或条件查询 |
| 主要目标 | 学习可迁移视觉表征 | 动作条件视频生成与世界建模 |
| 主要输出 | 用于下游任务的视觉编码器 | 可用于预测、评估、规划或动作提取的视频 |
| 时间建模 | 无显式时间维度 | 显式建模跨 $T$ 帧的运动和交互 |
| 前向/逆向统一 | 不涉及 | 通过切换被揭示实体统一两类查询 |
| 典型结构 | 非对称 ViT encoder–decoder | 预训练视频生成模型、条件编码和 LoRA 微调 |
| 推理时 mask | 通常不再是下游任务的控制接口 | 仍然是用户向世界模型发出查询的核心接口 |

## 区别一：随机遮蔽与语义化实体遮蔽

MAE 的 mask 通常是随机的。某个 patch 被遮蔽，并不意味着它代表机器人、动作或目标物体；其主要作用是控制信息缺失程度。

MVA 的 mask 则是语义化的：它揭示被选择实体在整个视频中的时空占据区域，例如：

- 机器人手臂和夹爪的运动；
- 被操纵物体的目标运动；
- 其他被选为条件的主动或被动实体。

所以，MVA 的 mask 不只是“哪些像素可以看见”，它还在表达：

> **哪个实体按照什么时空轨迹运动。**

这正是 Masked Visual Actions 中“Action”的来源。动作不再只表示为关节角、末端位姿或离散 token，而是与目标视频严格对齐的实体运动。

## 区别二：表征学习与条件生成

MAE 的训练终点主要是一个可迁移的视觉编码器。解码器服务于预训练阶段的像素重建，下游分类、检测和分割通常使用编码器表征。

MVA 的训练终点则是条件视频生成器。它需要输出完整视频，使结果能够用于：

1. 根据机器人轨迹预测物体和环境响应；
2. 根据目标物体轨迹合成机器人运动；
3. 模拟候选策略并进行排序；
4. 用想象轨迹代理评估策略；
5. 将生成的机器人视频交给逆动力学模型恢复低层动作。

因此，MAE 更接近：

```text
缺失像素重建 → 学习视觉表示
```

MVA 更接近：

```text
语义条件视频补全 → 查询世界模型
```

## 区别三：MVA 通过 mask 统一前向和逆向查询

这是 MVA 超出经典 MAE 类比的关键部分。

设主动实体集合为 $A$，例如机器人或人；被动实体集合为 $P$，例如被操纵物体。

### 前向世界模型查询

揭示机器人轨迹，预测未被给定实体的运动：

$$
p\bigl(\{e_i\}_{i\notin A}\mid\{e_j\}_{j\in A},I_0\bigr).
$$

语义是：

```text
机器人这样运动
→ 物体与环境将怎样响应？
```

### 逆向运动生成查询

揭示目标物体轨迹，预测其余实体，特别是机器人运动：

$$
p\bigl(\{e_i\}_{i\notin P}\mid\{e_j\}_{j\in P},I_0\bigr).
$$

语义是：

```text
希望物体这样运动
→ 机器人可能怎样完成它？
```

改变被揭示的实体集合，就改变了模型所回答的问题。这里的 mask 不再只是训练噪声，而是**查询算子**。

经典 MAE 不具备这种性质：改变随机 patch mask 不会让 MAE 在前向动力学和逆向运动生成之间切换。

## 区别四：空间纹理重建与时空交互生成

MAE 主要恢复单张图像中的空间外观。虽然重建需要理解对象和场景结构，但它不必显式预测未来运动。

MVA 不仅要补全纹理，还必须生成：

- 实体跨帧运动；
- 遮挡关系变化；
- 机器人与物体的接触；
- 物体对机器人动作的响应；
- 环境随交互发生的变化。

这使 MVA 更接近一种**语义化时空掩码条件生成**，或者说：

> **以实体轨迹为条件的视频 inpainting/world modeling。**

不过，生成出视觉上合理的接触不等于学到了真实因果动力学。MVA 仍可能产生幽灵接触、物体自主运动、穿模或跳帧。因此，它是强视觉条件接口，而不是已经得到物理保证的模拟器。

## 区别五：模型结构和计算路径不同

MAE 的标志性设计包括：

- 编码器只处理可见 patch；
- 被遮蔽 patch 不进入重型编码器；
- 轻量解码器负责像素重建；
- 约 75% 的高遮蔽率同时提高任务难度并降低编码成本。

MVA 并未采用这一套非对称 MAE 结构。论文使用 Wan-Fun-Control 2.2 14B 作为基础视频模型：

- 用与视频模型相同的自动编码器编码掩码条件；
- 通过特征拼接注入与视频空间对齐的条件；
- 使用 LoRA 微调，秩为 256；
- 训练批量大小为 4；
- 使用 8 张 H200，约训练 10,000 步、耗时 4 天；
- 适配数据约为 15 小时的真实与仿真掩码样例。

所以，MVA 借用的是“masked completion”的问题形式，而不是 MAE 的具体 encoder–decoder 架构和计算优化策略。

## 更准确的定位

MVA 与 MAE 的关系可以分成三个层次：

### 层次 1：抽象范式相似

二者都通过部分可见信息学习补全其余内容，因此都属于广义 masked modeling。

### 层次 2：任务语义不同

MAE 的 mask 主要表达“信息缺失”；MVA 的 mask 表达“实体动作或目标轨迹”。

### 层次 3：用途完全不同

MAE 主要服务于视觉表征预训练；MVA 主要服务于世界模型查询、策略评估、候选规划和逆向运动生成。

因此，最准确的判断是：

> **MVA 在形式上继承了 MAE 的“部分可见—其余补全”思想，但真正的创新是将 mask 设计为实体级、时空连续且具有动作语义的控制接口。**

## 一个直观类比

```text
MAE：
随机隐藏静态图像的一部分
→ 重建缺失像素
→ 学习图像表征

MVA：
有语义地揭示视频中某个实体的运动
→ 生成其他实体和环境的时空演化
→ 查询并使用世界模型
```

可以把 MAE 看作“补全视觉内容”，把 MVA 看作“用部分实体运动询问世界会怎样发展”。

## 我的判断

如果只从损失形式看，MVA 确实具有 MAE 式的 masked reconstruction 味道；如果从系统功能看，它更接近**实体条件的视频生成模型或视频修复式世界模型**。

MVA 的关键贡献并不是证明随机遮蔽也适用于机器人视频，而是提出：

1. 用实体级时空可见区域代替低维动作向量；
2. 让动作条件与视频模型的预训练视觉空间对齐；
3. 通过切换条件实体，在同一生成模型中表达前向和逆向查询；
4. 将生成视频进一步用于策略评估、规划和动作提取。

因此，“MVA 是 WAM/世界模型中的 MAE”可以作为帮助理解的第一层类比，但应立即补充：

> **它不是随机 patch MAE，而是 action-semantic masked video completion。**
