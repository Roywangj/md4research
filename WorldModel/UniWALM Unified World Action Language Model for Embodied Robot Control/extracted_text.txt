Abstract: Motivated by the human ability to integrate experience across language, perception, and
action, we introduce UniWALM, a unified world-action-language model that learns video, action, and
language in a single shared representation, where each modality is both a conditioning signal and a
supervision target. We ask: can jointly generating language enrich this shared representation, im-
proving manipulation and supporting memory-dependent behavior? Unlike prior approaches that at-
tach a reasoning or vision-language model to a video-action backbone and run them as distinct stages,
UniWALM unifies all three modalities inside a single mixture-of-transformers backbone whose per-
modality diffusion heads co-denoise synchronously, decoding subtask and textual memory in the same
pass as action with no separate planning stage; the generated language is re-consumed on the next step,
closing a language-as-memory loop without an external planner or memory bank. To keep the action
stream reliable under this richer objective, we further introduce Flow Matching with Correction (FMC),
a training objective that teaches recovery from perturbed action trajectories at no inference-time cost.
UniWALM consistently improves over same-backbone baselines (e.g., FastWAM [1]) on compositional
pick-and-place (MolmoSpaces) and across the memory-dependent subset of RMBench [2], where it
reaches 34.5% without any pretrained language or reasoning model and exceeds Mem-0’s keyframe-
equipped setup (28.5%) using only a single anchor frame. On a real-world Find-the-Item task, gener-
ating textual memory lifts success from 11.1% to 61.1%, while state-of-the-art VLAs stay at or below
chance (≤33.3%).

Introduction
Humans integrate perception, language, and action in an any-to-any manner: regions like the posterior parietal and pre-
motor cortex continuously fuse afferent inputs with efferent motor copies [3], and cognitive representations are inherently
shaped by what an agent can do in the world [4, 5]. For embodied agents, language, video, and action are three comple-
mentary views of a single interaction; a unified representation should let each one inform the others: language guiding
physical prediction, visual dynamics grounding action, and action anchoring predictions in embodied behavior. Multi-
modal models have operationalized this framing for vision and text [6, 7, 8] but largely omit action and motor control.
The same substrate that integrates these modalities also remembers: the hippocampus, which the brain uses to recall past
experience, is also recruited to imagine the future and locate the self in time [9, 10]. We routinely enlist language itself as
working memory (counting out loud, repeating a phone number, silently rehearsing a passage while reading to retain it)
to track state through long-horizon, memory-dependent tasks. A truly unified representation should therefore not only let
modalities inform one another but also let generated language serve as the working memory that threads behavior across
step boundaries. Concretely, because language is co-denoised with action in one representation, the generated string
serves as a learned, in-loop plan (next subtask) and textual memory (what has been done so far), while an anchor-frame
visual memory preserves scene context across occlusion; re-consumed on the next step, these close a memory loop with
no external planner, VLM, or retrieval buffer.
Recent robotic foundation models connect video, language, and action, but typically along only a subset of these direc-
tions. Vision-language-action models [11, 12] consume language as fixed conditioning but do not generate it. Chain-
of-thought VLAs [13, 14, 15, 16, 17] generate intermediate language within a control step, but autoregressively, so
action must wait for token decoding, and the generated string is not re-consumed across steps. World-action mod-
els (DreamZero [18], FastWAM [1]) co-model video and action but drop language entirely. Memory-augmented sys-
tems [19, 20, 2] attach retrieval buffers or an external planner to a pretrained backbone; π0.7 [20] supplies language from
a high-level semantic policy while a separate world model generates subgoal images that condition a VLA (Fig. 1(f)). On
memory-dependent evaluations like RMBench [2]’s M(n) subset, where decisions require n task-relevant past observa-
tions, policies that condition only on the current frame and prompt collapse.
A natural response is to compose a pretrained vision-language model with a video-action backbone and supply reasoning
via auxiliary conditioning or an additional loss (Fig. 1(f)). This family (hybrid planner + VLA systems [20], concurrent
compositional WALMs) is more accurately described as WAM + VLM features: it typically uses two vision backbones
optimized for different objectives and only loosely coupled, treats language as an external hidden state rather than a
generation target, and bolts memory on as a separate retrieval module. UniWALM (Fig. 1(g)) uses a single video backbone
jointly optimized for all three modalities, with video, action, and language as first-class diffusion heads co-denoised in
one pass; the generated language is re-consumed next step, closing a language-as-memory loop with no external planner,
VLM, or memory bank. Where prior world-action models supervise the backbone with frame-level predictive structure
(future video), UniWALM adds a task-level predictive stream (future subtask and task state as language), a second, longer-
horizon supervision signal that frame prediction alone cannot cheaply express.
In this work we study two questions: (i) does jointly generating language enrich the shared representation of a video-
action model and improve manipulation? (Fig. 1(g)) and (ii) can a policy use its own generated language, re-consumed
across steps, as working memory on memory-dependent tasks? (Fig. 2)
Contributions.
We introduce UniWALM, a multimodal world-model architecture that takes a step toward any-to-any
modeling across language, video, and actions, where each modality serves as both a conditioning signal and a supervision
target. Specifically:
• World-Action-Language Model (WALM): We introduce WALM, a unified World Action Language Model imple-
mented as a mixture of transformers that takes video, language, and actions as input and generates all three as output.
The language stream emits a subtask and textual memory in the same denoising pass as action, and re-consumes them
as prompt on the next control step, closing a language-as-memory loop. UniWALM’s language and action experts are
trained from scratch on a video-only backbone: no pretrained language or reasoning model is used.
• Flow Matching with Correction (FMC). We introduce FMC to improve the reliability of generated actions. During
training, FMC perturbs action trajectories and supervises a corrective velocity that returns the perturbed denoising path

Related Works
Generalist Visuomotor Policies.
Generalist robot policies [11, 22, 23, 24, 25, 14, 26, 27] improve over single-task
models [28, 29] by initializing from vision-language backbones [30, 31, 32, 33, 34, 35] and training for action. These
policies map observations to actions but do not model world dynamics or reason over long-horizon subtasks.
World-Action Models.
A recent line of works [1, 18, 36, 37, 38, 39, 40] adds a video-prediction objective, jointly
modeling world dynamics and action. FastWAM [1], closest to our work, couples a pretrained Wan2.2 [41] video DiT
with a parallel action DiT through unified attention. These models treat language purely as a conditioning input, never as
a generation target and provide no mechanism for subtask reasoning or memory.
Reasoning, Memory, and Hybrid Policies.
Long-horizon and memory-dependent tasks have motivated explicit rea-
soning and memory [2, 42], and hybrid systems [20, 43, 44, 45, 46] that combine a high-level VLM planner, a low-level
policy, and a video model to imagine action effects. Because these components are trained separately on heterogeneous
data, they lack a shared representation and execute planning and control asynchronously.
Unified and Omnimodal Models.
Any-to-any modeling originates in multimodal LLMs [8, 7] which omit generating
actions, and vision works like 4M [6], which unify many modalities via masked token modeling but target perception rather
than control and do not reason. Concurrent work [46] additionally generates actions, DINO features, semantics, and video,
but cannot reason or preserve memory during manipulation. Concurrent omnimodal models such as Cosmos 3 [47] extend
any-to-any modeling to action within a single framework, but decode text autoregressively in one tower and continuous
modalities by diffusion in another, running reasoning and generation as separate stages in a 64B model. UniWALM
instead generates language, video, and action entirely by diffusion in one shared representation, denoising language and
action synchronously so that reasoning and control co-refine in a single unified model.
An extended discussion contrasting UniWALM with CoT / inner-monologue policies, multi-scale memory VLAs, and
recent unified models is deferred to Sec. A.
3
UniWALM
UniWALM jointly models the future video, robot actions, and language within a shared multimodal representation, en-
abling reasoning and control to be learned together. Next, we describe its world-action-language formulation, multimodal
co-training, and corrective flow-matching objective.
3.1
Reasoning with Video Action Models
Video Action Models typically map the current observation and a coarse prompt to near-term video and actions, with
no explicit mechanism to generate language that can reason about subtasks or maintain task memory. We introduce
UniWALM, a World Action Language Model (WALM) that jointly generates future video, actions, and language within
a unified model. Its language generation expert is a diffusion model that provides language reasoning in the form of
subtasks and memory.

Generating Video, Action, and Language.
Given a pretrained video model, the observation frames are encoded first
and passed through the video DiT. We replicate the video DiT’s structure, matching its depth (30 layers) while reducing
hidden dimension, to define the action and language DiTs, whose weights are initialized from scratch. Each layer of the
video, action, and language DiT processes features via unified self-attention enabling feature sharing between modalities.
Training the Language Expert for Reasoning.
Per-frame RGB prediction captures short-horizon dynamics but cannot
cheaply carry task-level information (what subtask is active, what has been done), and we need this signal produced in
the same pass as action rather than through a separate autoregressive planner. We therefore adopt a discrete language
diffusion [48] expert that denoises in tandem with video and action, giving us speed and architectural symmetry with the
video model. At each training step we perturb ground-truth text (LGT ) depending on the diffusion time step, t, and predict
the correct token embedding (ˆL) using a cross entropy objective (Llang):

3.3
Memory
UniWALM integrates three memory mechanisms directly into the shared representation: a textual memory that is re-
consumed as the next-step prompt (closing a language-as-memory loop without an external planner), a visual memory that
admits one or more keyframes, and a task-completion channel that gates when the textual memory is updated. Full im-
plementation details (RoPE-shifted keyframe tokenization, task-completion supervision, and RMBench-specific training
configuration) are in Sec. B.4.
Textual Memory Re-consumption.
Policies that reason once per step cannot carry information across step boundaries,
which is exactly what long-horizon and memory-dependent tasks require. At inference, the language head emits a compact
string (subtask ∥textual memory) in the same denoising pass as action. For memory-dependent tasks, this string is re-
consumed as prompt on the next control step, closing a language-as-memory loop without an external planner or memory
bank.
Visual Memory.
Textual memory alone struggles with scene state that is hard to describe in words (precise object
locations, occluded layouts), so we add a lightweight visual-memory stream F the policy can always attend to. For tasks
that hide or move objects mid-episode, F preserves the layout otherwise lost as observations advance.
Task-Completion Signal (β).
If the textual memory is rewritten at every control step, intermediate reasoning overwrites
past progress and the summary ceases to be a reliable record of what has been done, especially since the language stream
has no explicit supervision for when a subtask is actually complete. We therefore co-train a 1-D task-completion channel
β, appended to the action vector, that fires at subtask completion and gates when the textual memory is updated, so the
memory advances only at subtask boundaries rather than every step. Because β is concatenated into the action vector, it
is supervised jointly with the action by Laction (Sec. 3.2) and requires no additional loss term.
Taken together, these three mechanisms correspond to three distinct learned abstractions over the task that live in the
shared representation: the generated subtask is a plan (what to do next), the generated textual memory is a running
summary (what has been done), and β is a task-completion signal (when to commit a subtask as done). All three are
first-class outputs of the same backbone that generates video and action, not external modules bolted onto a pretrained
VLM or retrieval buffer.

Implementation Details.
Our approach initializes from a Wan2.2 pretrained model and attaches an action and language
DiT expert. We fine-tune the video backbone with LoRA (rank 256) [52], restricting its update to a low-rank subspace.
This reduces trainable parameters and makes optimization easier and more stable on limited data. During training, we
randomly drop proprioception with a probability of 10%, and use a single image as input. We ensure that the reasoning
tokens only attend to the visual features and input prompt and allow the action tokens to attend to the language tokens
during generation (Fig. 2). The model is trained with 8-bit AdamW optimizer [53, 54] on 12 H200 nodes with 8 gpus
each for 44 hours. We use an image resolution of 224 x 448 for simulator (two views) and 224 x 672 (three views) for
real world experiments. The language and action DiT are initialized from scratch. We turn off video generation during
inference, similar to FastWAM, and the language DiT runs synchronously with the action DiT. Unoptimized UniWALM
without language generation runs at 76 ms and with the language expert runs at 123 ms to generate an action chunk of
32 with 10 denoising steps. Our model allows interleaved language generation by caching language features from the last
step to choose the frequency of language generation.
Full training configuration: action chunk N = 32, video horizon H = 5, 20 action and language denoising steps at
inference, batch size 3840, learning rate 4e−4, 15k steps on the 221K-trajectory MolmoSpaces mixture (the ablation
in Tab. 4 uses a 38K Pick&Place subset). Our model generates 64 language tokens for each diffusion forward process.
Data Flexibility.
UniWALM by construction has a modular architecture and training objective that supports co-training
(by masking attention) on heterogeneous data (e.g., video-only, video-action, video-VQA, and video-action-VQA) within
one representation. We validate the design on in-domain video-action and reasoning data and leave large-scale multi-
source co-training to future work.
4
Experiments
We evaluate UniWALM along two axes: Q1: does jointly generating language enrich the shared representation of a
video-action model and improve manipulation? Q2: can a policy use its own generated language as working memory on
memory-dependent tasks? The evaluation setup involves five simulation tasks on MolmoSpaces, the memory-dependent

Q1: Language generation improves manipulation.
On MolmoSpaces (Tab. 1), UniWALM surpasses MolmoBot on
all Pick&Place variants by +7% on average without video history, despite using neither video history nor a large-scale
pretrained vision-language generator (only the Wan2.2 video backbone is pretrained; language and action DiTs are trained

Wan2.2 backbone and action DiT structure, and is effectively the frame-level world model ablation of our co-training

our gains grow with task compositionality (highest on Pick&Place-NextTo and Pick&Place-Color), indicating the unified
representation contributes most where reasoning and placement precision, not raw reaching speed, are the bottleneck.

Conclusion.
We present UniWALM, a single-representation WALM that jointly denoises video, action, and language,
and re-consumes its generated language as working memory for the next control step. Without any pretrained language
or reasoning model, UniWALM achieves state-of-the-art on MolmoSpaces Pick&Place (+14.8 pts over FastWAM), lifts
real-world Find-the-Item from 11.1% to 61.1%, and reaches 34.5% on RMBench M(n), exceeding both memoryless
baselines and Mem-0 [2]’s keyframe-equipped setup while using only a single anchor frame.
Limitations.
Failures include grasping complex geometries and cluttered scenes. On RMBench we observe cases where
the subtask and textual memory correctly track state but the action expert fails to execute it (e.g., subtask-boundary
over/undershoot from task-completion timing lag; Fig. 12), and near-identical observations with different underlying
memory occasionally confuse the model; the full list of failure modes is in Sec. C.
Future Work.
We aim to scale multimodal co-training (ego-video, VQA, grounding), extend FMC to learn from the
model’s own rollout errors, and extend visual memory to multiple keyframes; see Sec. D for extended directions.

A
Related Works
Generalist Visuomotor Policies.
Generalist robot policies [11, 22, 23, 24, 25, 14, 26, 27] improve over single-task
models [28, 29] by initializing from vision-language backbones [30, 31, 32, 33, 34, 35] and training for action. These
policies map observations to actions but do not model world dynamics or reason over long-horizon subtasks.
World-Action Models.
A recent line of works [1, 18, 36, 37, 38, 39, 40] adds a video-prediction objective, jointly
modeling world dynamics and action. FastWAM [1], closest to our work, couples a pretrained Wan2.2 [41] video DiT
with a parallel action DiT through unified attention. These models treat language purely as a conditioning input, never as
a generation target and provide no mechanism for subtask reasoning or memory.
Reasoning, Memory, and Hybrid Policies.
Long-horizon and memory-dependent tasks have motivated explicit rea-
soning and memory [2, 42], and hybrid systems [20, 43, 44, 45, 46] that combine a high-level VLM planner, a low-level
policy, and a video model to imagine action effects. Because these components are trained separately on heterogeneous
data, they lack a shared representation and execute planning and control asynchronously.
17


--- PAGE 18 ---
Unified and Omnimodal Models.
Any-to-any modeling originates in multimodal LLMs [8, 7] which omit generating
actions, and vision works like 4M [6], which unify many modalities via masked token modeling but target perception rather
than control and do not reason. Concurrent work [46] additionally generates actions, DINO features, semantics, and video,
but cannot reason or preserve memory during manipulation. Concurrent omnimodal models such as Cosmos 3 [47] extend
any-to-any modeling to action within a single framework, but decode text autoregressively in one tower and continuous
modalities by diffusion in another, running reasoning and generation as separate stages in a 64B model. UniWALM
instead generates language, video, and action entirely by diffusion in one shared representation, denoising language and
action synchronously so that reasoning and control co-refine in a single unified model.
World-Action Models (WAM background).
World-Action Models (WAMs) [1, 18, 36] extend video-generation back-
bones with a parallel action head so that action prediction can leverage the priors learned by large-scale video pretraining.
FastWAM [1] — the WAM we compare against throughout — initializes from a pretrained Wan2.2 [41] video DiT and
attaches a matched action DiT whose tokens attend to the video tokens through a per-layer unified self-attention, followed
by a cross-attention over proprioception and the task prompt. Language is consumed only as fixed conditioning; there is no
language expert and no memory over time. UniWALM keeps the same video backbone and unified-attention mechanism
but adds (i) a language DiT that co-denoises subtasks and textual memory alongside action, (ii) an anchor-frame visual
memory, and (iii) the FMC training objective; the FastWAM-to-UniWALM delta therefore isolates these three additions
under matched backbone.
Multi-scale memory VLAs (π lineage).
MEM [19] equips a pretrained VLA with mixed-modal memory: a short-
horizon stream of recent video frames compressed by a video encoder, and a long-horizon stream of language capturing
abstracted semantic progress (e.g., which recipe stages are complete). π0.7 [20] builds on the π0.6-MEM architecture
and inherits the same memory design. Both approaches thus combine visual and textual memory, similar to UniWALM.
Two key differences: (i) MEM and π0.7 attach memory to a pretrained VLM/VLA backbone (autoregressive), whereas
UniWALM’s language and action experts are trained from scratch on top of a video-only backbone; and (ii) UniWALM
co-denoises language, action, and video synchronously in a single unified diffusion representation, whereas MEM’s long-
horizon text summary is produced autoregressively by the pretrained VLM.
Language-generating policies (CoT lineage).
A closely related line of work generates intermediate language during
control: Inner Monologue [13], RT-2’s chain-of-thought [14], Embodied CoT (ECoT) [15], RT-H language action hier-
archies [16], and CoT-VLA [17] predict rationales, subtasks, or “language actions” autoregressively and consume them
as conditioning for the next action within the same control step. UniWALM differs on three axes. First, language is
co-denoised synchronously with action in a single unified diffusion representation rather than produced autoregressively
before conditioning. Second, the generated string is re-consumed as prompt on the following control step, closing an
explicit memory loop across time rather than serving as within-step reasoning. Third, UniWALM supports both vi-
sual memory via anchor frames and textual memory via generated language, whereas the CoT lineage above uses only
language-side reasoning. This distinction matters for memory-dependent tasks such as Find-the-Item: policies that reason
once per step cannot carry information across step boundaries, whereas UniWALM’s readout persists as retrievable state.

and press the respective button K times where K is the number displayed above the button. The robot then needs
to press the confirm button. This task involves remembering the count of button presses followed pressing the
confirm button.
• Blocks Ranking Try: The scene contains three colored blocks in a random initial arrangement and a confirm
button. The task is to discover a specific target permutation by trial: the robot rearranges the blocks, hits the
confirm button, receives feedback on whether the arrangement is correct, and repeats. Between attempts, the
policy must retain which orderings have already been ruled out so it does not repeat a failed one.
• Cover Blocks: The robot faces three colored blocks and three covers. It first places a cover on each block from
left to right, then must remove the covers in a fixed color order (red, then green, then blue) and return each cover
to where it started. Because the blocks become visually hidden after covering, solving the second phase requires
remembering which block was placed under each cover.
• Battery Try: A pair of batteries with random initial poses and a two-slot holder are staged on the table. The
robot iteratively tries (battery, slot, orientation) combinations until both batteries seat correctly; combinations
that previously failed must be recalled so the same attempt is not repeated.

B.4
Memory Architecture Details
The following architecture choices for UniWALM’s memory channels apply across all benchmarks, independent of the
specific evaluation setup.
Visual Memory.
UniWALM conditions on one or more visual-memory keyframes captured during the episode. In our
current experiments we use a single anchor frame F taken at episode start, which provides a persistent visual reference
of the initial scene layout (e.g., pre-occlusion object positions) that is otherwise lost as later observations advance. Each
visual-memory frame is passed through the same VAE encoder as the current observation and concatenated along the
token dimension into the video stream, so the language and action DiTs attend to it via the shared unified self-attention.
To avoid position-encoding overlap with the current observation, we shift the RoPE [58] coordinates of each visual-
memory frame by the frame width W and vary the 0th RoPE coordinate based on video timestep. The design accepts
an arbitrary number of frames (e.g., a bank of task-relevant keyframes selected online), but we defer multi-frame visual

Task-Completion Supervision.
Task-completion signals are sparse, so we supervise the appended 1-D channel as a
step function within each action chunk: 0 before the subtask completes and 1 at and after the completion timestep. Being
part of the action vector, the channel is trained by the same flow-matching objective Laction, with no extra head or loss
term.
B.5
Flow Matching with Correction (FMC) Ablations on 2D Robot Trajectories
To isolate the effect of FMC’s perturbation hyperparameters without confounds from downstream task-success noise,
we ablate FMC on a controlled 2D robot-trajectory benchmark. The dataset (Fig. 10) consists of noisy demonstrations
grouped into seven canonical motion classes representative of common robot end-effector trajectories (circle, star, spiral,
line, arc, figure-8, square). The policy must learn to generate trajectories that match the full distribution of each class.
The sweep varies three FMC hyperparameters:
• s — the perturbation scale: standard deviation of the Gaussian noise ϵ1 ∼N(0, sI) added to the clean action x0 to
produce the perturbed sample xp
0 = x0 + ϵ1 (same s as in Sec. 3.4).
• d — the drift strength: magnitude of the temporally correlated drift (a normalized 2D random walk along the time
axis) that structures how the perturbed trajectory accumulates offset from the clean one; iid noise corresponds to d = 0.
• tcorrupt — the corruption time threshold: minimum diffusion time at which the correction branch is active. For
t < tcorrupt the model trains with standard flow matching; for t ≥tcorrupt it trains the correction target vcorr.
Each model is trained for 200k steps, and we evaluate 500 generated vs 1000 ground-truth trajectories per class using
symmetric Chamfer distance in the flattened trajectory space. Chamfer is the appropriate signal here because FMC’s
correction induces a different noise-to-data bijection than the baseline, so paired endpoint drift is dominated by this change
of mapping rather than trajectory quality. The configuration adopted in the main paper (s=0.4, d=0.3, tcorrupt≥0.5) falls
out as the winner of the sweep, with the strongest average Chamfer improvement and wins on 5 of 7 trajectory classes
(Tab. 6).

C
Limitations
UniWALM exhibits four main failure modes. (i) Boundary misfires: the memory loop tracks state correctly but the task-
completion signal β fires one step late or early, causing an extra or missed press (Fig. 12; detailed case in the Failure Case
subsection above). (ii) Incorrect subtask prediction: on near-identical observations with different underlying memory
state, the language stream occasionally emits the wrong next subtask. (iii) Grasp precision: complex-geometry objects
and cluttered scenes still bound task success. (iv) Inference speed: generating an action chunk of 32 with the language
expert at 10 denoising steps runs at 123 ms (76 ms without language; Sec. 3.5), which may be too slow for high-frequency
closed-loop control.
D
Additional Future Work
Beyond the directions in the main paper, the UniWALM formulation opens several concrete extensions.
Pretrained VLM initialization for the language DiT.
Our language DiT is trained from scratch. Initializing it from a
pretrained vision-language model would inject broad semantic priors into the language-memory loop without altering the
shared-denoising interface.
Retrieval-augmented memory with a learned selection criterion.
The current textual memory is a single running
string. Coupling it with an external episode log and a learned selection policy (choosing which past states or memory
snippets to re-inject into the prompt) would extend the loop to long horizons and cross-episode settings.
FMC from a replay buffer of the robot’s own mistakes.
FMC currently perturbs clean actions with Gaussian noise
ϵ1. A stronger variant is to construct the perturbation from the model’s actual rollout deviations: store rollout error pairs
and train the correction target to recover the nominal path from these empirical errors rather than synthetic noise.
Confidence-based flow matching.
A learned confidence head c ∈(0, 1] over the predicted velocity, trained jointly with
a log-penalty to prevent trivial collapse, would let the policy down-weight uncertain action predictions and expose an
inference-time signal for guarded execution and targeted re-planning.
Multi-keyframe visual memory.
Our visual-memory stream already supports an arbitrary number of frames (Sec. 3.5),
but our experiments use a single anchor frame. A natural extension is to maintain a running history of keyframes (either at
fixed intervals or selected online by the model) so the policy can attend to a bank of task-relevant past observations rather
than a single snapshot at episode start.
Balancing multiple conditioning signals.
When several conditioning streams are provided (e.g., a multi-keyframe
visual-memory history, textual memory, current observation, and proprioception), careful training is required to prevent
the policy from shortcutting to whichever stream is most predictive on the training distribution and ignoring the rest: for

alignment. Making this trace faithful (grounded in the actually-executed action), tamper-resistant, and expressive enough
to cover safety-critical constraints is an important direction for future research.
