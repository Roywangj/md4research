# Translation notes / 翻译说明

- **Source identity:** The source is the supplied 22-page PDF `4EBWNIZ3/...RoboMemArena A Comprehensive and Challenging Robotic Memory Benchmark.pdf`, arXiv:2605.10921v1 (11 May 2026). No historical `WorldModel/` directory or other paper was used.
- **Output contract:** `detailed_paper.md` is the complete bilingual reader; `paper.md` is a byte-for-byte copy. English and Chinese prose use paired `Para. X` / `Para. X[CN]` blockquotes. Equations use Markdown `$...$` / `$$...$$`; exact prompts, JSON keys, literals, model names, metrics, numbers, and citations are retained.
- **Coverage:** Main text, abstract, Figures 1–5, Tables 1–4, all references, and Appendices A–H (including exact generation/training prompts, JSON schema, asynchronous protocol, Algorithm 1, ratio rubric, all 26 task descriptions, reactive failure modes, real-world tasks, and verification distribution) are represented.
- **Figures/assets:** Fourteen 120-dpi full-page PNG renders are included under `assets/`. Full-page rendering was chosen to preserve axes, legends, table rows, prompt illustrations, and page context; the Markdown also transcribes substantive tables for searchability.
- **Reference policy:** The bibliography is preserved in original English bibliographic form, with a bilingual policy note. This avoids altering names, titles, venues, DOI strings, URLs, and arXiv identifiers.
- **Material caveats:** The two-column PDF text layer contains occasional line-order artifacts. Figure S2 includes a visibly corrupted carrot glyph in the supplied PDF; the rendered source page remains authoritative. The body reports 68.9%, while the Figure 3 graphic labels a rounded 68.8%; both are retained rather than silently normalized. Some Table S2 task names are line-wrapped in the PDF and were reconstructed from adjacent source lines without changing numerical values or task semantics.
