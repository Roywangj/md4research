# Translation notes / 翻译说明

- **Source format / 源格式:** User-supplied searchable PDF, arXiv:2610.30991v1, 14 pages, dated 22 Oct 2026 (Shanghai Jiao Tong University MVIG, Shanghai Innovation Institute, Noematrix). Text was extracted using PyMuPDF (`fitz`), and all multi-column flows, formulas, and figure captions were verified against original page geometry.
- **Coverage / 覆盖范围:** Full supplied PDF from title, authors, affiliations, abstract, Sections 1–5, Equation (1), Figures 1–5, Tables 1–4, and all 51 reference entries. All substantive sections, experimental configurations, ablation tables, discarded designs, and limitations are fully translated into Chinese without omissions or degradation into high-level summaries.
- **Pairing / 对照:** English source text is immediately followed by its Chinese translation using standard `Para. X:` / `Para. X[CN]:` blockquotes with distinct hex colors (`#3B82F6` and `#F59E0B`). Paragraph numbers align one-to-one across the entire paper (47 body paragraphs + 5 figure blocks + 4 table blocks).
- **References strategy / 参考文献策略:** Bibliographic author names, venues, identifiers, page ranges, years, and arXiv/DOI strings are fully retained in original searchable English. Accurate Chinese title translations are appended as italicized annotations for all 51 references.
- **Figures and tables / 图表:** All 5 figures and 4 tables were tightly cropped from the PDF at 250 dpi and saved into `assets/` and `images/`. For all substantive tables (Tables 1, 2, 3, 4), both the cropped image and the complete, searchable Markdown transcription are embedded.
- **Formulas & Literals / 公式与技术常量:** Standard `$...$` and `$$...$$` are enforced throughout; no `\(...\)` or `\[...\]` delimiters remain. Core terms such as UniFlowWAM, MM-DiT, MM-RoPE, Flow Matching, 4D VAE, and DINOv3 are kept in their canonical standard forms.
- **Validation / 校验:** `paper.md` is generated as an exact byte-for-byte copy of `detailed_paper.md`. Local image assets, bilingual pairing, caption matching, JSON schema integrity, and file boundaries have been validated using `validate_detailed_paper.py`.
