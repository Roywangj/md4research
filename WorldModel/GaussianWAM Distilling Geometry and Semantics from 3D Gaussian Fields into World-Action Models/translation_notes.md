# Translation notes / 翻译说明

- **Source format / 源格式:** User-supplied searchable PDF, arXiv:2608.24714v1, 13 pages, dated 25 Aug 2026. Text was extracted with `pdftotext -layout`; page renders were inspected for multi-column ordering, figures, and tables.
- **Coverage / 覆盖范围:** Full supplied PDF from title, author affiliations, abstract, Sections 1–5, all equations (1)–(15), Figures 1–5, Tables 1–4, searchable table transcriptions, conclusion, and all 34 reference entries. The PDF contains no separately titled appendix, supplementary material, algorithm block, limitations, availability, or acknowledgments section; this absence is recorded rather than inferred.
- **Pairing / 对照:** English source text is immediately followed by its Chinese translation using `Para. X:` / `Para. X[CN]:`. Lists in the contributions block and searchable Markdown tables are preserved.
- **References strategy / 参考文献策略:** Bibliographic author names, venues, identifiers, page ranges, years, and URLs are retained in original searchable English. Chinese title glosses are added as indented lines and do not replace the source records.
- **Figures and tables / 图表:** Main figures and tables were rendered from the supplied PDF at 150 dpi and cropped into `assets/figure_1.png`–`assets/figure_5.png` and `assets/table_1.png`–`assets/table_4.png`. The Markdown contains both linked crops and searchable transcriptions for substantive tables.
- **Uncertainty / 不确定性:** The PDF text extraction splits some words at line endings and uses typographic names such as `VGGT-Omega`; wording was reconstructed against rendered pages without changing model names, values, units, citations, or equation numbering. “Grounding” and “rollout” are retained as technical English terms where a forced Chinese equivalent could reduce precision.
- **Validation / 校验:** `paper.md` is generated as a byte-for-byte copy of `detailed_paper.md`; local image paths, bilingual labels, caption balance, JSON validity, and file-boundary constraints should be checked with the supplied validator and boundary script.
