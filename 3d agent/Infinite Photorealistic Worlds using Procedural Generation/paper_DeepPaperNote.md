# Infinite Photorealistic Worlds using Procedural Generation

## 原文摘要翻译

本文提出 `Infinigen`，一个面向自然世界照片级真实三维场景的程序化生成器。`Infinigen` 完全由程序驱动：从形状到纹理的每项资产都由随机数学规则从零生成，不使用任何外部资源，因此允许无限变化与组合。系统广泛覆盖自然世界中的对象与场景，包括植物、动物、地形，以及火、云、雨、雪等自然现象。`Infinigen` 可以为对象检测、语义分割、光流和三维重建等多种计算机视觉任务生成数量无限且多样的训练数据。作者希望它能成为计算机视觉及其他领域的有用资源。

## 创新点

1. **全链路完全程序化。** 不仅场景摆放，资产形状、材质和微观几何也由随机规则生成，并且不依赖外部静态资产。
2. **以真实网格替代视觉伪几何。** 系统拒绝凹凸贴图、透明遮罩和法线插值等只改变外观的捷径，让渲染细节与三维真值尽量一致。
3. **把艺术家节点图编译为可组合代码。** 节点图转译器允许艺术家通过熟悉的可视化界面贡献生成器，同时让系统随机化节点结构并与 Python/C++ 规则组合。
4. **按相机像素预算生成几何。** 动态分辨率缩放使每个网格面在最终图像中小于约一个像素，避免远处资产也使用近景级细分。
5. **提供面向学习任务的真值管线。** 深度、法线、遮挡边界和分割从网格直接提取，减少透明、体积和模糊效果对渲染通道真值的污染。

## 一句话总结

`Infinigen` 的核心不是“能无限出图”，而是把自然世界拆成一组可组合、可控、带真实几何的概率程序，从而让图像、三维资产和稠密标注共享同一生成来源；不过参数空间无限并不自动意味着真实分布覆盖无限，而且它仍是一套高成本离线生成系统。

## 研究问题

三维视觉需要大量精确几何真值，但真实图像的深度、遮挡边界和光流难以大规模获取。传统合成数据虽然标签便宜，却往往依赖有限静态资产库，而且主要覆盖驾驶、室内或人造对象；模型容易记住资产身份，自然对象的细枝、叶片、珊瑚、岩石和流体现象又长期缺位。

论文因此追问：能否不用任何外部资产，以紧凑数学规则生成自然对象从宏观结构到微观表面的全部几何与材质，同时自动输出任务真值？作者选择牺牲实时性，优先追求资产分布的可扩展性和几何标签一致性。

## 数据与任务定义

### 生成空间

最终系统统计到 `182` 个程序化资产生成器和 `1070` 个可解释自由度，另含 `50` 个程序化材质生成器。自由度只计入具有可理解语义、能在合理范围内插值并仍产生照片真实资产的参数，例如山体高度或生物肢体比例；低层噪声和物理模拟内部状态未计入，因此它是内部随机空间的下界，但参数间相关性又可能让简单求和高估独立维度。

## 方法主线

### 机制流程

1. **程序规则输入：** 输入是场景类型配置、随机种子和可选用户参数；节点图转译器将艺术家的着色/几何节点图编码成可组合函数，输出可采样的概率资产生成器。
2. **资产与场景组合：** 输入是地形、植物、生物、流体、天气等生成器；系统采样高低层自由度，并用泊松盘采样、程序掩码和自然先验放置对象，输出轻量全局占位地图。
3. **视点相关实例化：** 输入是全局地图和相机轨迹；系统仅实例化可见资产，按投影像素更新网格分辨率，并对密集散布使用实例化复用，输出材质和真实微几何完整的局部场景。
4. **渲染与标注：** 输入是局部高精场景；`Cycles` 路径追踪生成图像，自定义几何管线提取深度、法线、边界和分割，输出可直接训练视觉模型的图像—真值对。

*论文原图编号：Fig. 13。布局、资产实例化、材质/位移和最终渲染的核心数据生成链。*

### 概率资产：高层可控参数与低层随机细节

每个生成器针对一个资产子类，如山体、树或鱼。高层参数提供人类可解释控制，默认分布由作者调到接近自然外观；低层参数控制山体每个点、枝条扰动或表面噪声。材质生成器同时生成颜色/反射着色器和对应局部几何，所以粗糙岩面、树皮或叶片细节不仅存在于像素中，也存在于网格中。

树木使用随机游走与空间殖民，珊瑚使用差分生长、拉普拉斯生长或反应扩散，流体使用 `FLIP`，地形由分形噪声、物理模拟、符号距离场和移动立方体法生成。生物的基因组是一棵部件树，可生成身体、肢体、头尾、材质、毛发、绑定和姿态。

### 场景组合与世界一致性

系统不是只为单幅图摆景，而是先生成可从多个相机位置观察的广域、视点一致世界。它在低分辨率地表上用泊松盘采样候选点，并用坡度、噪声和地形属性调节密度；`11` 个场景配置编码“仙人掌常见于沙漠”“陡坡上树木较稀”等简单自然先验。这个设计支持立体、视频和多视角数据，但生态共现关系仍来自人工规则，不是从真实数据统计学习。

### 动态分辨率与真实几何真值

固定相机后，系统把资产细分到每个面投影后小于约 `1 px`。远处对象少分面、近处对象高分面；草、苔藓等密集资产使用少量原型的随机变换实例。即便如此，平均完整场景仍有约 `1600` 万多边形。

![Figure 14](3d%20agent/Infinite%20Photorealistic%20Worlds%20using%20Procedural%20Generation/images/page_007_fig_figure_14.png)
*论文原图编号：Fig. 14。同一内容在 `10 m`、`30 m`、`85 m` 距离下采用不同网格分辨率，但最终图像差异不明显。*

`Cycles` 以 `1920×1080`、每像素 `10000` 个样本渲染。标注不依赖 Blender 内置渲染通道，而直接从网格提取；表面法线通过局部深度拟合减少草地等高频表面的混叠，并可禁止跨越遮挡边界采样。其工程意义是“看见的细节”和“监督中的几何”尽可能来自同一实体。

## 关键结果

### 覆盖与资源成本

`182` 个生成器和 `1070` 个自由度说明系统规模可观，但不能直接当成视觉多样性或真实覆盖率。更硬的工程数字是：在两颗 `Intel Xeon Silver 4114` 和一张英伟达显卡上，一对 `1080p` 立体图平均需要 `3.5` 小时墙钟时间，其中约 `1` 小时使用 GPU，平均内存约 `24 GB`。

![Figure 15](3d%20agent/Infinite%20Photorealistic%20Worlds%20using%20Procedural%20Generation/images/page_008_fig_figure_15.png)
*论文原图编号：Fig. 15。`1000` 次独立试验中的墙钟、内存、CPU/GPU 小时和三角形数分布。*

### 立体匹配迁移

在独立 `Infinigen` 评测集上，本数据训练模型的 `Bad 3.0` 为 `5.527%`，优于 `TartanAir` 的 `6.504%`、`SceneFlow` 的 `7.837%` 及其他训练集。这证明其分布与已有合成集明显不同，也证明模型能泛化到未共享资产的同生成器样本；但它仍是生成器内评测，不能单独证明真实域迁移。

在 `Middlebury` 上，本方法平均 `Bad 3.0` 为 `29.7%`，弱于 `SceneFlow` 的 `25.0%`，也略弱于 `FallingThings` 的 `28.6%`。其亮点集中在含自然对象的盆栽样例：`35.2%` 优于三个对照训练集的 `41.3%`、`43.3%` 和 `45.1%`。这正好支持“补足自然域”而非“通用立体训练集全面更强”的定位。

## 深度分析

### 真正贡献：可扩展的三维“世界模型代码库”

论文所谓程序化，本质上是把领域知识压缩进代码：树的生长、珊瑚的形态发生、岩石侵蚀和生物拓扑都以可采样模型表达。它带来的不是纯数据量，而是可追溯因果控制——同一个场景可以改变几何、材质、天气或相机并重新获得一致真值。这对诊断模型、定向生成难例和构造反事实数据尤其有价值。

### 为什么自然对象上有效

现有合成立体集多为室内、驾驶或散落人造物体，自然域中的细枝、重复纹理、非刚性表面和多尺度遮挡不足。`Infinigen` 刻意在这些几何上投入高分辨率真实网格，因此模型在植物样例上获益是分布覆盖和标签一致性的共同结果。相反，生成器几乎没有人造平面和大面积无纹理区域，所以 `Middlebury` 平均结果退化也符合机制预期。

### 三个容易混淆的“无限”

第一是**样本数无限**：随机程序可持续采样。第二是**程序支持无限变化**：连续和离散参数组合非常大。第三是**真实分布覆盖无限**：这并未被证明。手写 `182` 个生成器依然规定了资产族、拓扑和参数分布；若作者没有编码某种长尾自然现象，它就不会因多采样而出现。

同样，“照片级真实”不等于“传感器级真实”。路径追踪和微几何提高视觉可信度，但相机噪声、运动、天气传感效应和真实生态分布仍可能存在差距。论文缺少真实自然深度基准，只能用定性视差图间接支持 sim-to-real。

## 局限

1. **生成器偏置仍然强。** 规则、参数范围和场景共现由开发者手工设计，尚无真实数据驱动的分布拟合与覆盖审计。
2. **跨真实域证据不足。** 自然场景没有定量深度真值；野外结果主要是可视化，无法排除选择性展示或未知误差。
3. **域专化带来明确退化。** `Middlebury` 平均指标不占优，说明只在自然世界训练不能替代更均衡的合成数据混合。
4. **计算成本高。** `3.5` 小时/立体对、约 `1 GPU` 小时和 `24 GB` 内存使大规模在线采样昂贵，`10000` 次每像素路径追踪也偏向高质量离线渲染。
5. **自由度不是严格多样性指标。** 参数可能相关，外部可解释维度也忽略内部随机状态；`1070` 不能直接与真实数据熵或有效样本数对应。
6. **真实几何仍不等于真实物理。** 网格标签更一致，但材料、动力学、生物运动和流体近似是否足以支撑具身交互，论文没有验证。

## 我的笔记

- **可复用思想：** 用相机投影误差控制几何细分，比固定多层细节更适合可微渲染、生成式三维和具身数据管线。
- **系统接口启发：** 节点图转译器是一个很漂亮的“艺术家前端—代码中间表示”桥梁；后续语言模型也可以操作同一中间表示，自动生成或修改资产程序。
- **建议复现实验：** 混合 `Infinigen` 与 `SceneFlow` 训练，并按自然/人造、纹理/无纹理、细结构/大平面分层测试，验证两类数据是否互补而非互相干扰。
- **值得补做：** 以真实图像检索或视觉语言模型估计生成器参数，比较人工先验与数据拟合分布对 sim-to-real 的影响。
- **与后续工作的关系：** `Infinigen Indoors` 延续了资产程序化底座，却用约束语言解决室内人工环境的布局规律；两者共同说明“世界代码”需要同时描述对象如何长成和对象如何组织。
