## 原文摘要翻译

真实世界的空间智能要求模型在一个连续、不断演化的三维世界上进行推理；然而现有的视觉语言模型与工具增强智能体大多仍停留在对孤立视觉观测的静态、无状态推断上。

我们提出 S-Agent，一种面向连续多视图图像与视频的「理解与推理」空间工具调用智能体范式。

它把空间推理形式化为「时空证据累积」，而非孤立的帧级预测，从而把空间感知从以帧为中心的识别，重塑为以场景为中心的理解。

具体而言，S-Agent 把视觉语言模型当作语义规划器，由它决定需要什么证据；同时由一套分层的空间工具与专家在二维中定位物体、将其提升到三维几何证据、再把这些证据聚合为高层空间知识（如计数、测量、朝向与相对位置）。

此外，一种时间记忆机制——用于维护演化场景状态的场景记忆（Scene Memory）与用于累积推理上下文的智能体记忆（Agent Memory）——使证据能够跨帧、跨推理步整合。

在多视图与视频空间推理基准上的全面实验表明，S-Agent 能以免训练的方式一致提升开源与闭源视觉语言模型。

除推理期增强外，对 S-Agent 生成的空间轨迹数据 S-300K 做监督微调，得到紧凑空间智能体 S-Agent-8B；它显著超越同规模基线（如 Qwen3-VL-8B），并与先进闭源模型（如 GPT-5.4 与 Gemini 3）表现相当。

## 创新点

- **把空间推理重定义为「时空证据累积」**：不再让模型从单帧一次性预测，而是把每帧看作对隐藏三维场景的局部、瞬时投影，由智能体沿空间维与时间维主动累积可复用证据。作者明确指出，视频空间智能缺的不是更强的二维/三维识别，而是这种跨空间、跨时间的证据累积机制——这是全文动机的落点。
- **「语义规划」与「空间证据获取」彻底解耦**：视觉语言模型只负责决定「要测什么、要比什么」，几何计算与感知交给确定性工具/专家，输出还能写进记忆复用。这避免了让模型在自由文本里做不可靠的度量与关系推理。
- **三级空间证据层级**：二维定位 → 二维到三维几何提升 → 五类空间专家聚合，把碎片化的感知与几何线索逐级抽象为场景级空间知识。消融显示「原始三维证据需经专家解释」才真正有用（见后文）。
- **双记忆设计**：场景记忆（实体中心，去重并保持物体身份）与智能体记忆（记录思考、调用、失败与中间结论）分工明确，前者用 Merge 合并、后者用 Append 追加。
- **轨迹蒸馏出紧凑智能体**：把强 teacher（GPT-5.4 规划器）的完整工具调用轨迹拆成「最终答案 / 回合级 / 专家级」三种监督，构成 S-300K，把 agentic 空间能力内化进 8B 模型，使其逼近闭源大模型。

## 一句话总结

S-Agent 把视频/多视图空间推理从「单帧单次预测」改造成「VLM 规划器主动调用分层空间工具 + 双记忆累积时空证据」的智能体过程，免训练即可一致提升强 VLM，并能蒸馏出逼近闭源模型的紧凑 S-Agent-8B。

## 研究问题

![Figure 1](3d%20agent/S-Agent%20Spatial%20Tool-Use%20Elicits%20Reasoning%20for%20Spatial%20Intelligence/images/page_001_fig_figure_1.png)
*Fig. 1：S-Agent 总览。它把空间推理形式化为时空证据累积——含 VLM 语义规划器、一套分层空间工具，以及维护演化场景与推理历史的双记忆系统。*

**要解决的技术问题。** 空间智能是指理解物体之间以及物体与三维环境之间的几何关系，是视觉语言模型走向通用人工智能的关键一步。但当前模型主要在被动的二维图文语料上训练，缺乏显式三维监督或具身经验，由此产生一道**语义到几何的鸿沟**：模型擅长概率性、定性的语义推断，却常被语义先验与文本模式带偏，无法忠实捕捉高保真几何。

**现有路线的短板。** 近期 agentic 视觉语言模型（如用程序合成做三维推理的 VADAR、用强化学习协调多工具的 SpaceTools、用形式化参考系约束的 GCA、引入三维重建与相机操作的 Think3D）确实拓宽了空间理解的边界，但它们大多仍聚焦于**静态图像或孤立观测**。而真实三维世界是隐藏的、演化的，不断被投影成二维观测流；仅从孤立二维视图推理，根本上难以维持物体状态、跨视角与时间整合证据、并建立对底层场景的连贯理解。

**核心主张。** 缺的不是更强的二维/三维识别，而是一种能沿空间与时间两个维度累积证据的推理机制。S-Agent 把视觉语言模型当作语义规划器，由工具/专家与时间记忆提供对具体场景持续、显式的三维感知，从而让智能体基于「累积证据」而非「孤立视觉印象」推理。

## 数据与任务定义

**任务形式化。** 给定问题与一组或一段视觉观测（可以是视频，也可以是同一场景的多视图图像集），目标是产生一个依赖**底层三维场景状态**、而非单一二维投影的答案。模型把推理实现为一个迭代的证据求取过程，逐步获取并复用与场景相关的空间证据（符号化定义见后文方法主线）。

**评测基准（四个，覆盖多图与视频）。**

| 基准 | 输入形态 | 主要考察 |
| --- | --- | --- |
| MMSI-Bench | 同一场景多图 | 跨视角整合：位置关系、几何属性、运动感知、多步空间推理 |
| ViewSpatial-Bench | 多视角 | 视角相关定位：相机视角 / 人物视角下的朝向与相对方向 |
| ReVSI | 动态视频 | 从动态观测做三维空间推理（难从单帧恢复的关系） |
| VSI-SUPER | 长视频 | 空间变化推理：物体、视角、布局随时间如何变化 |

**两种设置。**

- **零样本（免训练）**：直接用强 VLM（GPT-5.4、Gemini 3 Pro）作为工具调用规划器，不做任何任务训练。
- **训练设置**：以 Qwen3-VL-8B-Instruct 为骨干规划器，在零样本 S-Agent 生成的轨迹上做监督微调，得到 S-Agent-8B。

**基线三类。**

- 先进闭源 VLM：Gemini 3 Pro、GPT-5.4、Grok 4
- 开源通用 VLM：Qwen 系列、InternVL3.5
- 空间专用模型：Cambrian-S、VST-SFT、SenseNova-SI 系列

## 方法主线

### 机制流程

S-Agent 的一步推理可拆成四个环节，循环往复直到证据足以作答：

1. **输入**：问题 $q$、视觉观测 $\mathcal{F}$、当前场景记忆 $S_t$ 与智能体记忆 $H_t$。规划器读取它们。
2. **操作（规划→调用→观测）**：规划器产生证据请求 $r_t$；某一级工具/专家执行该请求，返回观测 $o_t$。
3. **记忆更新**：把 $o_t$ 拆成「可复用场景证据 $e_t$」与「过程上下文 $c_t$」，分别写入两个记忆。
4. **输出去向**：更新后的 $(S_{t+1}, H_{t+1})$ 反馈给规划器进入下一回合；当累积证据足够时终止并作答。

形式化地，规划器 $\pi_\theta$ 把问题、观测与记忆映射为证据请求：

$$r_t = \pi_\theta(q, \mathcal{F}, S_t, H_t)$$

工具/专家执行后返回观测并更新两个记忆状态：

$$(S_{t+1}, H_{t+1}) = \mathrm{Update}(S_t, H_t, r_t, o_t)$$

这把「语义规划」与「空间证据获取」分开：模型决定测什么、比什么，工具与记忆提供具体场景的时空证据。与把每次工具调用当作孤立动作的固定流水线不同，S-Agent 的每个证据请求都同时以问题与演化记忆为条件，因此感知与几何计算按需触发、其输出可在后续步骤复用。

*Fig. 2：S-Agent 流水线。VLM 作语义规划器、空间工具与专家作场景专属证据提供者、记忆作跨视角/帧/推理步的持久三维状态载体。*

### 模型结构：三级空间证据层级

用 $T^{(1)}, T^{(2)}, T^{(3)}$ 表示三级工具集，给定请求 $r_t$ 选择某级工具产生观测：

$$o_t = T^{(k)}(r_t, \mathcal{F}, S_t),\quad k\in\{1,2,3\}$$

**Level 1 — 二维视觉证据获取。** 从原始二维观测里抽取与问题相关的图像级线索：选关键帧、用 VLM 定位指代实体、用开放词表检测器框出候选区域。它既能直接回答简单问题，也为后续三维提升与推理提供观测。

- `detect_objects_tool`：基于 GroundingDINO 的开放词表检测，返回框、置信度、标签、位置描述与可视化。
- `vlm_ground_objects`：两阶段多帧定位——先由 VLM 在候选帧上「可见性投票」，再在最优帧上调检测器取最终框。
- `depth_estimation_tool`：图像级深度线索，支撑简单的前后/遮挡判断（区别于 Level 2 的完整三维）。
- `TStarKeyframeSearchTool`：视频关键帧搜索，先选信息量大的帧再做上述感知。

**Level 2 — 二维到三维几何提升。** 把图像级证据提升为带几何的场景表示。主力工具 `metric_depth3d_tool` 基于 Depth-Anything-3，给定多图与查询点/框，估计度量深度、三维坐标、相机位姿与深度可视化，为下游专家提供共享的三维基底。这一步让碎片化的二维观测能在同一空间里比较，把表观尺寸与物理尺度区分开。

**Level 3 — 空间知识聚合（五类专家）。** 把二维/三维线索抽象为高层、场景专属的空间知识，减少模型在自由文本里做不可靠度量/关系推理：

| 专家 | 职责 | 关键做法 |
| --- | --- | --- |
| Metric Measurement | 度量距离/尺寸 | 复用框，查 Level 2 取三维点，按最近点/中心点/最长边等路线确定性计算 |
| Counting | 计数（含条件计数） | 检测候选框、跨帧归一化、非极大值抑制去重再聚合 |
| Visual Orientation | 物体自身朝向 | 看正反面、把手、屏幕、开口、对称性等外观线索 |
| Relative Position | 三维方位关系 | 把框提升到共享三维系，按物体间/自我中心/视角条件/方位锚等路线比较 |
| Object-Centric View | 以物体多视角组织的问题 | 把标注视角映射到题目所需空间系再判关系 |

### 关键实现细节：双记忆

每个工具观测都按不同方式更新两个互补记忆——可复用的场景内容并入场景记忆，请求/观测/推理上下文记入智能体记忆：

$$S_{t+1} = \mathrm{Merge}(S_t, e_t),\qquad H_{t+1} = \mathrm{Append}(H_t, c_t)$$

- **场景记忆（Scene Memory）**：实体中心的演化记忆，把跨帧、跨视角、跨尺度、跨指代的重复观测绑定到持久实体，累积其视觉与几何属性。它**不是稠密重建**，而是「问题条件化」的空间记忆，只保留当前查询所需证据。存两类内容：实体（别名、支撑帧、定位证据、几何属性）与派生事实（关系/测量及其来源证据）。新观测要么链接到已有条目，要么新建。
- **智能体记忆（Agent Memory）**：保存通往场景理解的推理过程——思考、发出的调用、返回观测、失败信息、中间结论。它让规划器知道「已经试过什么、哪里仍不确定、下一步该求什么」，避免重复调用、遗漏未决项或自相矛盾。

### 训练目标：轨迹蒸馏 → S-Agent-8B

S-Agent 还能当 teacher 训练紧凑智能体。数据取自 SenseNova-SI-800K（与所有评测基准完全不相交）。

- **数据生成**：用 Qwen3-VL-8B 多次 rollout 估计样本难度，优先挑学生「不确定/不稳定」且可能需要工具的样本（度量、计数、相对位置、相机/视角、依赖定位的题）。冻结的 teacher（GPT-5.4 规划器）生成完整轨迹（提示、响应、调用、观测、中间产物、记忆状态、最终答案、评测结果）。
- **数据过滤**：只保留「执行有效且最终答案正确」的轨迹。选择题要求最终 `<answer>` 选项精确匹配；数值题按平均相对精度（MRA ≥ 0.6）过滤；文本题按归一化匹配。注意：**是否调用工具不作为硬过滤标准**，由规划器自行决定何时该调。
- **数据分解**：每条保留轨迹拆成三种监督——最终答案轨迹（学端到端推理）、回合级轨迹（在部分上下文下学迭代决策、缩短超长上下文）、专家/工具轨迹（提升工具调用与专家级推理）。一条 rollout 由此变成多粒度信号。

S-Agent-8B 把 MMSI 从 31.1 提到 41.6（+10.5），说明蒸馏教会的不只是答案，更是可复用的工具调用与证据整合范式。

### 消融到底说明了什么（Table 5）

在 ViewSpatial 上、以 GPT-5.4 为规划器，逐级累加证据与记忆：

| 配置 | 平均 |
| --- | --- |
| 仅 VLM | 45.6 |
| + Level-1 二维证据 | 49.0 |
| + Level-2 三维证据 | 49.8 |
| + Level-3 三维专家 | 56.7 |
| + 场景记忆 | 58.2 |
| + 智能体记忆 | 57.6 |
| 完整 S-Agent | 60.0 |

最强信号：**加 Level-2 原始三维证据几乎无益（49.0→49.8）**，但**加 Level-3 专家骤升到 56.7**。作者解释：原始三维证据含稠密数值（相机位姿、深度、噪声重建点），模型难解读、甚至被带偏；只有经专家过滤、转成任务化的测量/关系/结论，三维证据才真正有用。记忆模块再把分数从 56.7 推到完整的 60.0。

### 失败或不稳定设置

- **弱规划器反向**：S-Agent(Qwen3-VL-8B 未训练) 在 MMSI 仅 30.7，低于基座 31.1。
- **原始三维证据无效**：Level-2 单独只 +0.8。
- **记忆单项**：智能体记忆单加（57.6）略低于场景记忆单加（58.2），价值在二者组合。
- **VSI-SUPER 的 VSC（Table 7）**：S-Agent 在 VSR 长视频上大胜，240 分钟设置超 Cambrian-S-7B-LFP 约 37.2 个点，得益于帧选择工具。
- 但在变化推理 VSC 子集上未超该 LFP 基线，长时段几乎为 0，作者因此不过度解读。

## 深度分析

![Figure 4](page_012_fig_figure_4.png)
*Fig. 4：工具落地的空间推理定性例。原始 VLM 在线索不全时凭二维表观误判，S-Agent 用分层工具与深度引导的位置专家恢复三维关系。*

### 为什么有效

- **把不可靠的隐式几何外置成显式、可复用证据。** 模型只做语义决策，几何由确定性工具算，结果还能写进记忆——这正对应 Figure 4：直接问 GPT-5.4，因目标被遮挡而凭表观二维布局猜错；S-Agent 在初次 grounding 失败后没有立刻作答，而是改用检测器并尝试语义近义词（"desk phone"）找回框，再由位置专家经深度提升到三维（架子 (−0.52, 1.21)、电话 (−0.34, 1.46)），从俯视布局读出「架子在电话左后方」得出正确答案。
- **专家是用好三维证据的关键。** 消融的 L2→L3 跃升（49.8→56.7）直接证明：噪声几何必须被专家解释成任务标量才有用。这条结论对「把几何当显式证据喂给 VLM」的任何工作都很关键。
- **记忆契合跨帧任务。** ReVSI 上 S-Agent 在相对方向、路径规划最佳，这些题需要跨帧/跨视角整合，恰是场景记忆（去重、保持身份）与智能体记忆（避免重复/矛盾调用）发挥作用之处。

### 与强基线/替代路线的定位

- 相对 VADAR / SpaceTools / GCA / Think3D 等 agentic 路线：它们多停在静态图或单次观测、或程序合成，S-Agent 加入时间记忆与连续多视图/视频的有状态证据累积。
- 相对长视频的两类常见做法：帧压缩（采样/检索/摘要）可能丢失关键空间证据；reconstruction-first（先建完整三维）算力浪费且把几何当固定上下文。S-Agent 是按需、问题条件化、可复用的稀疏证据，介于两者之间。
- 相对 Cambrian-S / SenseNova-SI / Spatial-MLLM / VST 等训练驱动单次模型：它们把空间能力压进参数、一次前推作答；S-Agent 把能力外置到工具+记忆，再用蒸馏把这种行为内化进 8B。

### 复杂度与扩展性

- 工具栈是真实模型而非伪代码：检测用 GroundingDINO、度量三维用 Depth-Anything-3、关键帧用 T*-style 搜索，与本地仓库已下好的 checkpoint 完全对应，复现门槛不高。
- 但**论文未报告推理时延、平均工具轮数与算力开销**——多轮调用 + 三维重建对在线场景可能偏重，是工程落地需量化的代价。

### 复现注意点

- **免训练收益依赖强规划器**：弱 8B 直接套用可能反向，要先用 S-300K 做 SFT。
- **消融范围有限**：层级与记忆次序只在 ViewSpatial + GPT-5.4 上验证，换 MMSI / 视频是否仍成立未知。
- **S-Agent-8B 仍是工具调用智能体**：SFT 在序列化轨迹上做，推理时仍发工具调用，故部署需带齐工具服务。

## 局限

- **强规划器依赖**：agentic 包装对弱规划器可能无益甚至有害（MMSI 30.7 < 31.1）。
- **原始三维证据需专家中介**：Level-2 单独几乎无效，体系对专家设计敏感。
- **消融与结论的外推性**：核心消融仅一基准一规划器；层级/记忆次序未在多基准复核。
- **长视频变化推理弱**：VSC 几乎为 0；且作者引用近期工作指出 VSI-SUPER 作为真实空间感知指标的可靠性受质疑，仅作参考。
- **效率未量化**：无时延、工具轮数、token 开销的报告，难判断相对单次推理的性价比。

## 我的笔记

- **与我的研究最相关的一条**：消融揭示「原始三维证据（深度/位姿/点云）会干扰模型，必须经专家转成任务化标量才有用」。这与我在推进的 [[deepscan-gem-mv-research-direction]] 直接呼应。
    - 把 Pi3 多视图几何当显式证据去抬升 BLINK-MV 时，不应直接喂几何，而应在几何与模型之间放一层「把几何转成结论」的专家——其相对位置 / 度量测量专家就是范本。
- **工具栈与本仓库高度重合**：检测用 GroundingDINO、度量三维用 Depth-Anything-3。
    - 二者正是 [[CLAUDE.md]] 里 `checkpoints/` 已下好的 GroundingDINO 与 DA3METRIC-LARGE 权重，复现门槛低；仍缺关键帧搜索与朝向/分割相关专家的接线。
- **基准重合**：MMSI-Bench、VSI 系列也是本仓库 Skill-3D 已准备好的评测；注意我之前记过的 [[skill3d-mmsi-harness-scoring-bug]]——读这张 MMSI 46.4 时要确认对方计分是否按选项字母，避免把口径差异当成方法差异。
- **可复用的数据配方**：难度采样（多 rollout 找不稳样本）+ 多粒度分解（final / turn / expert）是把单条 teacher 轨迹放大成 SFT 信号的好做法，可迁移到我自己的蒸馏实验。
- **待查**：平均工具轮数与时延、grounding 失败重试的稳健性、S-Agent-8B 推理是否仍显式发工具调用（看起来是）。
