## 总体脉络

当前 `Reasoning` collection 的主线是“视觉信息如何在长推理过程中保持有效”。问题通常不是 VLM 完全看不见图，而是文本 CoT 一长，视觉 token 的作用被稀释，模型逐渐靠语言先验或错误局部证据继续推理。

`TrainingFree` 线主要在测试时修补这个问题：`DeepScan` 先找证据再回答，`ICoT` 和 `DaP-ICoT` 把原图局部插入推理过程，`VisRef` 在推理中重注入视觉 token，`SDR-MCoT` 用熵判断是否需要长推理并逐步增强视觉注意力，`PRCR` 则从 KV cache 层面避免重复回放视觉 token。`REALM` 是 3D 方向的旁支，它不训练新的 3D 专用模型，而是用 MLLM-agent 和多视角 3DGS 渲染来做开放世界 3D reasoning segmentation。

`Train` 线则把“会看回来、会用图思考”变成模型参数中的能力。`Thyme` 通过 SFT + RL 学会写代码处理图像；`Qwen Look Again` 用 BRPO 与 visual token copy/route 训练反思式回看；`PatchCue` 和 `MINT-CoT` 把视觉 cue 或视觉 token 写进中间推理格式，再用 SFT/RL 学出来；`Reasoning in the Dark` 把可见中间步骤压缩为潜在文本与潜在视觉的联合状态；`Latent Visual Reasoning` 更进一步，把 ROI 视觉标记作为隐藏状态的重建目标，并用 `GRPO_latent` 优化潜在状态如何支持后续文本答案；`DeepEyes` 与 `DeepEyesV2` 让模型通过 RL 学主动感知和工具调用；`PFlowNet` 则把视觉行为抽象成 perceptual flow，并用 SFT + variational RFT 优化。

最值得警惕的是 `Position: Your VLM May Not Be Thinking with Interleaved Images`。它提醒我们：很多 “thinking with images” 的涨点可能来自 fine-tuning 改变了语言生成分布，而不一定来自模型真的利用了中间插入图像。因此读这组论文时，最好同时看“是否训练”“是否真的回看视觉证据”“插入视觉信息是否必要”三件事。

## 各论文简要概括

### REALM: An MLLM-Agent Framework for Open World 3D Reasoning Segmentation and Editing on Gaussian Splatting

REALM 用 3D Gaussian Splatting 渲染多视角图像，再让 MLLM-agent 在 global-to-local 流程中先粗定位目标、再生成局部近景做 3D mask。它适合放在 `TrainingFree`，因为核心卖点是无需大量 3D 专用 post-training，而是通过视角合成与 MLLM 编排完成 reasoning-based 3D segmentation。

### Thyme: Think Beyond Images

Thyme 让 MLLM 自主生成并执行代码，对图像进行裁剪、旋转、增强和数学计算。它是典型 `Train` 论文：先用约 500K SFT 数据激活代码/图像处理能力，再用 RL 和 GRPO-ATS 优化何时写代码、怎样写代码。

### DeepScan: A Training-Free Framework for Visually Grounded Reasoning in Large Vision-Language Models

DeepScan 是这组里最清晰的免训练视觉证据获取路线：先分层扫描局部线索，再通过视觉专家恢复证据区域，最后用混合证据记忆把细粒度证据和粗粒度上下文交给 LVLM。它更像一个测试时视觉信噪比控制器。

### Interleaved-Modal Chain-of-Thought

ICoT 认为文本 CoT 很难表达“这一步推理对应图中的哪一块”。它提出 Attention-driven Selection，直接利用 VLM attention map 选择原图局部区域插入推理步骤，不引入新参数，因此归到 `TrainingFree`。

### Let's Think with Images Efficiently

DaP-ICoT 针对 ICoT 的两个问题做改进：视觉内容插入位置太固定、视觉 token 不连续。它用动态视觉思考集成决定何时插入视觉信息，再用精确视觉思考引导选择更连贯的视觉内容，重点是减少冗余 token。

### VisRef: Visual Refocusing while Thinking

VisRef 直接处理长推理中的视觉稀释：在每个推理步骤用 DPP 选择相关且多样的视觉 token coreset，再重新注入上下文。它不做额外 RL fine-tuning，属于纯测试时 visual refocusing。

### Mitigating Low-Quality Reasoning in MLLMs

SDR-MCoT 解决两个低质量 MCoT 问题：简单题过度思考、复杂题视觉信息利用不足。它用首 token 熵估计置信度来决定是否需要长 CoT，并在每个推理步骤增强相关视觉 patch 的注意力，完全不插入额外视觉 token。

### Position Rebinding Cache Reuse

PRCR 关注 interleaved multimodal reasoning 的系统效率。它指出直接复用历史视觉 KV cache 会因为旧位置绑定导致 attention 错位，于是把视觉 KV 与原空间坐标一起存，再按当前解码位置重新绑定，达到近似 replay 的效果但大幅省算力。

### Qwen Look Again

Qwen-LA 是训练型“回看图像”路线。它用 BRPO 训练模型在推理中生成 vision-text reflection，并通过 Visual Token COPY / ROUTE 让模型重新关注视觉信息。它的核心不是测试时插件，而是把反思式回看写入模型行为。

### PatchCue

PatchCue 把视觉线索从像素级框或点改成 patch 级 cue，更贴近现代 VLM 的 patch-token 输入。它通过冷启动 SFT 学会输出 patch cue，再用 GRPO 和过程监督 cue reward 强化中间视觉推理步骤。

### MINT-CoT

MINT-CoT 面向数学图形推理，把相关视觉 token 自适应插入数学 CoT。它构建 54K 对齐数据，并用 text-only CoT SFT、interleaved CoT SFT、interleaved CoT RL 三阶段训练得到 MINT-CoT-7B。

### Reasoning in the Dark

IVT-LR 不生成可见中间 CoT，而是让每个潜在步骤结合上一隐藏状态与当前选中的图像 embedding。它先训练完整显式 CoT，再逐阶段替换为三个潜在视觉-文本步骤，以更少的自回归解码换取更高的 M3CoT 与 ScienceQA 准确率。其关键风险是中间轨迹不可读，且 attention 分析尚不能证明视觉证据的因果必要性。

### Latent Visual Reasoning

LVR 不把中间视觉证据显式插回序列，而是用 ROI 对应的视觉标记监督语言模型隐藏状态，在固定 4/8/16 个潜在步骤中重建视觉语义，再恢复文本解码。它在 MMVP 上把 Qwen2.5-VL-7B 的 66.7 提升到 72.0，但步数收益不单调、学习式停止失败，`GRPO_latent` 也只在部分设置增益；因此更准确的定位是“重建并强化初始编码中的视觉证据”，而不是获取新观察或证明隐藏状态具有可解释的视觉推理链。

### DeepEyes

DeepEyes 用端到端 RL 训练模型主动 “think with images”。它不依赖预先收集的 cold-start reasoning 数据，而是通过 active perception 和奖励设计让模型学会何时 zoom-in、如何把视觉证据放进推理。

### DeepEyesV2

DeepEyesV2 将方向推进到 agentic multimodal model：模型不仅看图，还能调用代码执行、web search 等工具。论文明确采用 cold-start + RL 两阶段训练，因为直接 RL 难以稳定诱导工具使用。

### Position: Your VLM May Not Be Thinking with Interleaved Images

这篇是立场/分析论文，不提出新的训练模型。它通过移除 interleaved images 和注意力可视化指出：近期 thinking-with-images 的性能提升可能主要来自 fine-tuning 后的语言分布改善，而不是中间图像真的被有效使用。

### Perceptual Flow Network for Visually Grounded Reasoning

PFlowNet 把视觉推理轨迹抽象成 perceptual flow，先用 SFT 学生成结构化视觉状态，再用 variational reinforcement fine-tuning 结合多维奖励和 vicinal geometric shaping，让模型学到更 reasoning-oriented 的视觉行为。它是 `Train` 线中对“视觉轨迹”建模最系统的一篇。
